手动指令

使用说明：① 打开台式电源给板子供电 → ② 板载 USB-C 插到电脑 → ③ 本页用 Chrome / Edge 打开 → ④ 点「连接串口」选 CH340 (COM 口) → ⑤ 点按钮控制测量。
注意：烧录固件用 ST-Link；本页只负责控制与数据回传（115200 8N1）。串口助手不能与本页同时占用同一 COM 口。快捷键 S / X / N 与按钮等效（输入框聚焦时除外）。
