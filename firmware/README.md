### 双斜率硬积分已从**两个**工程删除（2026-09-13）

原"模式二 双斜率硬积分"（<1 nA，下限约 6 pA）废弃，由**小电流模式**取代：
双斜率在 1 pA 时上积相要 `t1 = C·ΔV/I = 100pF×2V/1pA = 200 秒`，而预算只有
10 秒 —— 连一个循环都跑不完。小电流根本不需要参考电流拉回：1 pA 积 3 秒才
30 mV，离 ±4.3 V 的轨远得很，直接积、测首尾两点即可。

**还有一个当时没意识到的理由**：双斜率靠 `EN=0`（Hi-Z）做"零参考"，而那个
浮空节点的寄生电容会注入一个指数衰减的暂态电荷（实测 `C_p ≈ 4.9 pF`、
`τ ≈ 490 µs`、`Q ≈ 24 pC`）。小电流模式同样受它影响，但**可控** ——
把 `SI_SETTLE_TICKS` 加大到 `>5τ` 即可（已改为 128 次 ≈ 3.0 ms）。

> `SI_SETTLE_TICKS` 的单位是**阻塞 `ReadBoth` 的次数**（每次约 23.6 µs），
> **不是 160 µs 的 TIM6 拍**。旧注释写成"稳定拍数"会让读者差 6.8 倍。

## 扩展协议（仅本固件有）

在 `firmware-v1` 原有协议（`S`/`D`/`B`/`X`/`E`）之上增加以下指令。

### 为什么要用整数传系数

MCU 端**不做浮点文本解析**（`strtof` 体积大、行为受 locale 影响）。
系数一律用**定标整数**传：

| 量 | 定标 | 例 |
|---|---|---|
| 增益 `a` | × 1e6（ppm） | `a = 0.998765` → `998765` |
| 偏置 `b` | × 1e15（fA） | `b = -0.123 pA` → `-123` |

上位机负责换算，MCU 收到后转成 float 存。

### 量程分段（三个，按电流绝对值）

| 段号 | 量程 | 判定 |
|---|---|---|
| `0` | **1 pA – 1 nA**（小电流） | `\|I\| < 1 nA` |
| `1` | **1 nA – 10 nA** | `1 nA ≤ \|I\| < 10 nA` |
| `2` | **10 nA – 45 nA** | `10 nA ≤ \|I\| ≤ 45 nA` |

分段**按绝对值**，正负共用一段（增益误差与符号无关，正负各拟合一套会
让每段点数减半、统计可靠性下降）。报告如需按符号分表，导出 CSV 里带符号，
在 MATLAB 里筛即可。

### 用哪一路 ADC 出结果（重要）

**ADS8866（外部 16 位）是最终结果的标准**，内置 ADC 只作对照。
原因：内置是 12 位左移 4 位（有效分辨率 16 码），在 1 pA 量程下量化误差
达 25%；ADS8866 是 1 码，同样条件下 1.5%。

结果行**两路都报**，便于逐点对照（也便于报告里写"内置/外部一致性"）：

```
I=+25.274 nA X=+25.271 nA MODE=1 T=1000ms CAL=+25.270 RAW m=5003 n=6251 INT1=58962 INT2=2601 EXT1=58900 EXT2=2540
```

| 字段 | 含义 |
|---|---|
| `I=` | 由**内置 ADC** 算出的原始值（保持与原固件兼容） |
| `X=` | 由 **ADS8866** 算出的原始值 ← **拟合用的就是这个** |
| `T=` | 实际积分时长（ms）。模式一恒为 1000ms；小电流模式是设定值，撞轨提前收尾时更短 —— 报告里 `I = C·ΔV/T` 的 T 就是它，**必须记录** |
| `CAL=` | `X=` 经分段校准模型后的最终输出（未校准时不出这个字段） |
| ` TIMEOUT` | 后缀。本固件已无模式二，正常不会出现；保留解析是为了兼容 `firmware-v1` |
| `RAW …` | **模式一专属**的原始量，见下 |

> 上位机的 `I=` 解析正则不锚定行尾，追加字段不会破坏现有解析。

### `RAW` 段：模式一的原始量

| 字段 | 含义 |
|---|---|
| `m=` / `n=` | 窗口内 **POS / NEG 注入的周期数**。式(6) 的分母就是 `m+n` |
| `INT1=` / `INT2=` | 内置 ADC 那路的**窗口两端**原始码 |
| `EXT1=` / `EXT2=` | ADS8866 那路的窗口两端原始码 ← 拟合用这组 |

> `INT1`/`EXT1` 是**拉回相最后一拍**的采样（记作 `V_01`），不是 `voltage_buf[0]` ——
> 式(6) 用的端点就是它。见下文「窗口两端的对齐」。

**为什么要在结果行里带这些**：只报电流值的话，`m`/`n` 和两端码就丢了，
而这两件事都必须从**同一次测量**的原始量出发：

1. **离线复核** —— 拿实测的 `m`/`n`/两端码可以把式(6) 整个重算一遍，
   不用反推（报告表 4-9~4-14 要的也是这些量）
2. **分段系数 `a`/`b` 的拟合**

### 窗口两端的对齐（为什么分母就是 `m+n`）

**拉回相搬进了 TIM6 中断**，所以节拍是这样对齐的：

```
节拍 0..p        拉回相（把积分器拉到接近 0V，不计数、不进缓冲）
节拍 p           V_01 → 窗口起点          ← 就是这一拍
节拍 p+1..p+6250 窗口采样 → voltage_buf[0..6249]，每拍计一次数
```

窗口两端（`V_01` 与最后一个窗口采样）**都是 ISR 采样**，采样偏移完全相同；
而计数覆盖的正好是它们之间的 **6250 个间隔**。于是：

```
n_total = m_count + n_count = 6250      ← 不用减一
窗口时长 = 6250 × 160µs = 1.000 s 整     ← 不用再凑
```

**论文的 `(m+n)` 形式因此精确成立。**

> 为什么必须搬进中断：若在主循环里拉回，`V_01` 到采样点 0 的间隔是
> `160µs + 读一次 ADC 的耗时 + 启动 TIM6 的代码延时`，比整一拍多出后面两项。
> 那一截是实打实的参考注入但不属于任何一拍，折算约 0.5~1 pA 的恒定误差，
> 而且依赖编译结果、说不清来源。

小电流模式（`MODE=2`）**不出** `RAW` 段：它不算 `m`/`n`，用的是起点/终点两段
平均，原始量是另一套（`T=` 已经给了它的实际积分拍数）。

`tools/nanoammeter_capture.py` 会把这一段解析进 npz 的 `raw_m` / `raw_n` /
`raw_int1` … 字段；没有这一段时一律记 `-1`（**不伪造成 0**）。

### 校准系数指令

| 指令 | 作用 | 响应 |
|---|---|---|
| `C` | 查询分段系数 | 未标定：`CAL NONE`<br>已标定：`CAL 3 <a0>,<b0> <a1>,<b1> <a2>,<b2>` |
| `K<seg>,<a_ppm>,<b_fA>` | 写入某段系数 | 成功：`CAL SET <seg> <a_ppm>,<b_fA>`<br>失败：`CAL ERR <原因>` |
| `Z` | 清除**分段系数**（恢复 a=1, b=0） | `CAL CLEAR` |

响应示例：`CAL 3 998765,-123 1000234,56 999123,-12`

> **`C` 的响应格式不能追加字段** —— 上位机正则锚定行尾
> （`/^CAL 3 (\S+) (\S+) (\S+)$/`）。物理常数因此走下面单独一组指令。

### 物理常数指令（`q` / `I₊` / `I₋`）

计算电流要用的物理量：

```
I = q·(c2 − c1)/T窗 − (m·I₊ + n·I₋)/N          T窗 = N·160µs

  q = C·VREF/(65536·GAIN)   库仑/码
```

**`q` 的 4 个因子不必分开测** —— 只测乘积。而且 `C` 和电平移位增益**分不开、
也不用分**：`C` 在整个公式里只出现在 `q` 里。

| 指令 | 作用 | 响应 |
|---|---|---|
| `Q` | 查询物理常数 | `CAL Q <q_aC>,<i+_pA>,<i-_pA>` |
| `Q<q_aC>,<i+_pA>,<i-_pA>` | 写入 | 成功：`CAL Q SET <...>`<br>失败：`CAL ERR <原因>` |

定标：`q` 为 **aC/码**（×1e18，标称 `15259`），`I₊`/`I₋` 为 **pA**（×1e12，
实测 `50232` / `-50255`）。

**写入时会校验符号**（必须 `I₊ > 0 > I₋`）和量级。符号写反会让整个公式静默
反向 —— 这是本架构最容易出错也最难发现的地方，所以直接拒收而不是记下来。

**`Z` 不会清掉 `q`/`I₊`/`I₋`。** 它们是仪器的**实测属性**，不是拟合出来的修正；
清掉等于把仪器退回全标称状态。

### `q` 怎么测（没有精密源也能做）

```
参考断开（ADG 关），灌一个已知电流 I，积 T 秒，读首尾码差 Δc：

    q = I·T / Δc
```

两点一除，**没有拟合**。要求积分期间不撞轨（撞轨后码饱和，Δc 是假的）。
已知电流可来自源表（如 2636B，±0.1%）—— 接到**仪器输入端**，不碰参考通路。

系数存在 Flash 最后一页（`0x0803F800`），掉电不丢。

### 4. 已确认的物理事实（供报告用）

**参考电流的共模偏移以 1:1 进入读数**：

```
comp = [(m−n)·I + (m+n)·d] / N      d = (I₊ + I₋)/2
                                └─ 系数 ≈ 1, 无衰减
```

实测 `d = (50.232 − 50.255)/2 = −11.5 pA` → 每个读数偏 +11.5 pA。
**这台仪器的绝对准确度主要由两个参考电流的共模稳定性决定**，
I₊/I₋ 的温漂会 1:1 传进读数（报告 4.7 节不确定度预算里权重最大的一项）。
