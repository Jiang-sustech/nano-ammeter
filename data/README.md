### 已知弱点：`q` 的标准误偏大

`fit_constants.m` 的杠杆分析：端点项跨度仅 869 pA，计数项 89400 pA，
**杠杆比 103:1** → `M(q)` 相对标准误 **0.073%**，比 `I±` 的 0.001% 大 70 倍。
根因：窗口固定 6250 拍、锯齿周期由电流决定 → 终点相位 = `6250 mod 周期`，
**同一电流重复测相位相同**，重复测量只压噪声、不加端点跨度。

q 的误差是纯增益（进 a），**不影响线性度**。要改善得改用**开环**测量
（固定参考极性 + 灌已知电流 + 让 Δc 跑满斜坡），注意**不能靠"参考断开"**——
`EN=0` 是 Hi-Z 不是 0 A。

## 二·补二、误差口径（**三个必须分清的区分**）

> 2026-09-16 加。这三条我在讨论里连续搞混三次，用户逐条纠正后才固化。
> **引用精度数字之前先读这一节。**

### ① 输出偏差 ≠ 回读精度

```
档位      源精度（输出偏差）             回读精度（回读值的精度）
 1 nA     ±(0.15% rdg +  2 pA)        ±(0.15% + 240 fA)
10 nA     ±(0.15% rdg +  5 pA)        ±(0.15% +   3 pA)
100 nA    ±(0.06% rdg + 50 pA)        ±(0.06% +  40 pA)
```

- **输出偏差** = 实际输出对不对得上**设定值** → **与本实验无关**
  （已裁定"以回读值为准"，不用设定值当真值）
- **回读精度** = 回读对不对得上**真实流过的电流** → 只有这一列进不确定度预算

**引数字时必须说清是哪一列**，两列固定项差 1.7~8 倍。

### ② 系统误差被拟合吸收，只有随机误差进残差

校准的"真值"是**回读值**。所以：

- 回读的**系统**误差（例如整体偏高 0.15%）→ **被三常数拟合吸收** →
  **残差里看不见**，它藏在装置的**绝对准确度**里
- 回读的**随机/逐点**误差（噪声、逐点非线性）→ **才进残差**

**所以不能拿"回读的绝对精度"去解释残差。**（曾据此说"8 nA 处回读指标 ±15 pA
→ 残差受参考源限制"，被用户当场指出——那个数里主要是系统项，已被拟合吃掉。）

### ③ 残差是"装置 vs 回读值"之差，不是"装置 vs 真值"

```
残差 = Īₘ(校准后) − Iₛₜd(回读值)
```

**不能写成"装置的准确度"**，报告里必须注明比较基准。

### 实测到的量（2026-09-16）

| 量 | 值 |
|---|---|
| 回读**噪声**（10 nA 连采 40 次） | **σ ≈ 64 fA** |
| 校准后残差（**真验证点**，见下） | 绝对 RMS **1.65 pA**，最大 **3.536 pA** |
| 　正向 / 负向 | RMS **2.08** / **1.05** pA（**正负不对称**） |
| 未校准准确度（≥5 nA） | **+1.04% ± 0.04%**，纯增益 |

**3.5 pA 从哪来：未定。** 已排除：回读噪声（64 fA，小 50 倍）、`Δc` 量化（0.015 pA）、
`T` 的误差（纯增益，被 `q` 吸收）。

### 哪些点算"验证点"

- **标定点本身**（19 点）→ 样本内，**不算**
- **与标定点同电流、但另采一轮的点**（10/15/20/25/30/35/40 nA）→ **伪样本内**
  （装置在给定电流上读数近似确定，重复性 ~1 pA），**也不算**
- **只有插在标定网格中间的真交错点**（6 7 8 9 / 12.5 17.5 22.5 27.5 32.5 37.5 nA）算

（曾把三类混在一张表里报 "RMS 1.69 pA"，被用户抓出。）

### 要验**绝对**准确度，必须换独立参考

现在的基准（2636B 回读）自己也可能有系统偏差，而**它被拟合吃掉了**。
分离的唯一办法：**标准电阻 + 标准电压源（`I = V/R`）**，不确定度可到 0.01% 量级。

## 三、关键结论（详见根 README 与 docs/）

- **未校准准确度**：+1.0 ~ +1.3%（纯增益误差 + 约 1.3 pA 偏置）
- **线性度**：0.0137 % FS（≈ 11 pA / 80 nA）—— 比准确度好约 **100 倍**
- **两路 ADC**（内置 vs ADS8866）：斜率差 2 ppm，**换 ADS8866 对准确度没有帮助**
- **三常数拟合**：`q = 1.5546e-14 C/码`、`I₊ = +49.7172 nA`、`I₋ = −49.7428 nA`
  （标准误 0.002%），RMSE 1.50 pA，`cond(A) = 7.39`
- **交叉验证差 1.02%**：由拟合值反推 `R = 100.51 MΩ`，万用表读 99.48 MΩ ——
  差值落在万用表 100 MΩ 档 ±1% 的边缘，在不确定度之内
- **`EN=0` 的 Hi-Z 暂态是真的**：`C_p ≈ 4.9 pF`、`τ ≈ 490 µs`、`Q ≈ 24 pC/次`
  （示波器看到的 ms 级指数衰减主要是**探头自己的 10 pF** 造成的）
