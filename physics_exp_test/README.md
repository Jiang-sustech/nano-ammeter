# physics_exp_test — 实验表征固件

> ## ⚠️ 本工程是 `nano_ammeter/` 的**整份拷贝**

```
nano_ammeter/        竞赛交付固件（保持干净，不含表征机械）
physics_exp_test/    实验表征固件（本工程）
```

两者**源码独立**，因此**会漂移**。改动时请遵守下面的约定。

## 两个工程的分工

| | `nano_ammeter/` | `physics_exp_test/` |
|---|---|---|
| 模式一 电荷平衡（≥1 nA，1 秒窗口） | ✅ | ✅ |
| 模式二 双斜率硬积分（<1 nA，下限约 6 pA） | ✅ | **已删除** |
| **小电流模式**（纯积分+斜率，1 pA~1 nA） | ❌ | ✅ |
| 结果行带 `X=`（ADS8866 那一路） | ❌ | ✅ |
| 结果行带 `T=`（实际积分时间） | ❌ | ✅ |
| 波形回传 `B` / `X`、自检 `E` | ✅ | ✅ |
| 分段校准系数 `I_cal = a·I_raw + b` | ❌ | ✅ |
| 串口写入系数 + 掉电保存 | ❌ | ✅ |
| 底噪测量（`N` / `W`） | 仍在（待删） | **已删除** |

**为什么替掉模式二**：双斜率在 1 pA 时上积相要
`t1 = C·ΔV/I = 100pF×2V/1pA = 200 秒`，而预算只有 10 秒 —— 连一个循环都
跑不完，这就是"约 6 pA 下限"的由来。小电流根本不需要参考电流拉回：
1 pA 积 3 秒才 30 mV，离 ±4.3 V 的轨远得很，直接积、测首尾两点即可。

删除模式二顺带释放了 **8120 字节 RAM**（两个 2048×2 的逐 tick trace 缓冲）。

**这四项就是两个工程的全部差别**，其余代码应当逐字节相同。

## 防漂移约定

**改共享部分（`adc.c` / `ads8866.c` / `uart.c` / `sh1106.c` / `Drivers/` /
`cmake/` / 链接脚本 / 启动文件）时，两边都要改。**

改完用这条命令核对，**只应剩下那四项相关的差异**：

```bash
cd nanoammeter_repo
diff -r --exclude=build --exclude=.git --exclude=README.md \
     nano_ammeter physics_exp_test
```

如果 diff 出来的东西超出预期，说明有一边漏改了。

## 构建

```bash
cmake --preset Debug
cmake --build build/Debug          # 产出 physics_exp_test.elf
```

## 与上位机的关系

两个固件**共用同一个控制台** `../纳安表控制台.html`。
控制台里的「实验表征」面板只在与本固件通信时有用；
对着 `nano_ammeter` 用时该面板不会响应（系数查询无回包）。

## 扩展协议（仅本固件有）

在 `nano_ammeter` 原有协议（`S`/`D`/`B`/`X`/`E`）之上增加以下指令。

### 为什么要用整数传系数

MCU 端**不做浮点文本解析**（`strtof` 体积大、行为受 locale 影响）。
系数一律用**定标整数**传：

| 量 | 定标 | 例 |
|---|---|---|
| 增益 `a` | × 1e6（ppm） | `a = 0.998765` → `998765` |
| 偏置 `b` | × 1e15（fA） | `b = -0.123 pA` → `-123` |

上位机负责换算，MCU 收到后转成 float 存。

### 量程分段（三个，按电流绝对值）

| 段号 | 量程 | 判定 |
|---|---|---|
| `0` | **1 pA – 1 nA**（小电流） | `\|I\| < 1 nA` |
| `1` | **1 nA – 10 nA** | `1 nA ≤ \|I\| < 10 nA` |
| `2` | **10 nA – 45 nA** | `10 nA ≤ \|I\| ≤ 45 nA` |

分段**按绝对值**，正负共用一段（增益误差与符号无关，正负各拟合一套会
让每段点数减半、统计可靠性下降）。报告如需按符号分表，导出 CSV 里带符号，
在 MATLAB 里筛即可。

### 用哪一路 ADC 出结果（重要）

**ADS8866（外部 16 位）是最终结果的标准**，内置 ADC 只作对照。
原因：内置是 12 位左移 4 位（有效分辨率 16 码），在 1 pA 量程下量化误差
达 25%；ADS8866 是 1 码，同样条件下 1.5%。

结果行**两路都报**，便于逐点对照（也便于报告里写"内置/外部一致性"）：

```
I=+25.274 nA X=+25.271 nA MODE=1 T=1000ms CAL=+25.270
```

| 字段 | 含义 |
|---|---|
| `I=` | 由**内置 ADC** 算出的原始值（保持与原固件兼容） |
| `X=` | 由 **ADS8866** 算出的原始值 ← **拟合用的就是这个** |
| `T=` | 实际积分时长（ms）。模式一是固定 1000ms；小电流模式是设定值，撞轨提前收尾时更短 —— 报告里 `I = C·ΔV/T` 的 T 就是它，**必须记录** |
| `CAL=` | `X=` 经分段校准模型后的最终输出（未校准时不出这个字段） |
| ` TIMEOUT` | 后缀。本固件已无模式二，正常不会出现；保留解析是为了兼容 `nano_ammeter` |

> 上位机的 `I=` 解析正则不锚定行尾，追加字段不会破坏现有解析。

### 校准系数指令

| 指令 | 作用 | 响应 |
|---|---|---|
| `C` | 查询校准状态 | 未校准：`CAL NONE`<br>已校准：`CAL 3 <a0>,<b0> <a1>,<b1> <a2>,<b2>` |
| `K<seg>,<a_ppm>,<b_fA>` | 写入某段系数 | 成功：`CAL SET <seg> <a_ppm>,<b_fA>`<br>失败：`CAL ERR <原因>` |
| `Z` | 清除校准（恢复 a=1, b=0） | `CAL CLEAR` |

响应示例：`CAL 3 998765,-123 1000234,56 999123,-12`

系数存在 Flash 最后一页（`0x0803F800`），掉电不丢。
