# physics_exp_test — 实验表征固件

> ## ⚠️ 本工程是 `nano_ammeter/` 的**整份拷贝**

```
nano_ammeter/        竞赛交付固件（保持干净，不含表征机械）
physics_exp_test/    实验表征固件（本工程）
```

两者**源码独立**，因此**会漂移**。改动时请遵守下面的约定。

## 两个工程的分工

| | `nano_ammeter/` | `physics_exp_test/` |
|---|---|---|
| 模式一 电荷平衡（≥1 nA，1 秒窗口） | ✅ | ✅ |
| 模式二 双斜率硬积分（<1 nA，下限约 6 pA） | ✅ | **已删除** |
| **小电流模式**（纯积分+斜率，1 pA~1 nA） | ❌ | ✅ |
| 结果行带 `X=`（ADS8866 那一路） | ❌ | ✅ |
| 结果行带 `T=`（实际积分时间） | ❌ | ✅ |
| 波形回传 `B` / `X`、自检 `E` | ✅ | ✅ |
| 分段校准系数 `I_cal = a·I_raw + b` | ❌ | ✅ |
| 串口写入系数 + 掉电保存 | ❌ | ✅ |
| 底噪测量（`N` / `W`） | 仍在（待删） | **已删除** |

**为什么替掉模式二**：双斜率在 1 pA 时上积相要
`t1 = C·ΔV/I = 100pF×2V/1pA = 200 秒`，而预算只有 10 秒 —— 连一个循环都
跑不完，这就是"约 6 pA 下限"的由来。小电流根本不需要参考电流拉回：
1 pA 积 3 秒才 30 mV，离 ±4.3 V 的轨远得很，直接积、测首尾两点即可。

删除模式二顺带释放了 **8120 字节 RAM**（两个 2048×2 的逐 tick trace 缓冲）。

**这四项就是两个工程的全部差别**，其余代码应当逐字节相同。

## 防漂移约定

**改共享部分（`adc.c` / `ads8866.c` / `uart.c` / `sh1106.c` / `Drivers/` /
`cmake/` / 链接脚本 / 启动文件）时，两边都要改。**

改完用这条命令核对，**只应剩下那四项相关的差异**：

```bash
cd nanoammeter_repo
diff -r --exclude=build --exclude=.git --exclude=README.md \
     nano_ammeter physics_exp_test
```

如果 diff 出来的东西超出预期，说明有一边漏改了。

## 构建

```bash
cmake --preset Debug
cmake --build build/Debug          # 产出 physics_exp_test.elf
```

## 扩展协议（仅本固件有）

在 `nano_ammeter` 原有协议（`S`/`D`/`B`/`X`/`E`）之上增加以下指令。

### 为什么要用整数传系数

MCU 端**不做浮点文本解析**（`strtof` 体积大、行为受 locale 影响）。
系数一律用**定标整数**传：

| 量 | 定标 | 例 |
|---|---|---|
| 增益 `a` | × 1e6（ppm） | `a = 0.998765` → `998765` |
| 偏置 `b` | × 1e15（fA） | `b = -0.123 pA` → `-123` |

上位机负责换算，MCU 收到后转成 float 存。

### 量程分段（三个，按电流绝对值）

| 段号 | 量程 | 判定 |
|---|---|---|
| `0` | **1 pA – 1 nA**（小电流） | `\|I\| < 1 nA` |
| `1` | **1 nA – 10 nA** | `1 nA ≤ \|I\| < 10 nA` |
| `2` | **10 nA – 45 nA** | `10 nA ≤ \|I\| ≤ 45 nA` |

分段**按绝对值**，正负共用一段（增益误差与符号无关，正负各拟合一套会
让每段点数减半、统计可靠性下降）。报告如需按符号分表，导出 CSV 里带符号，
在 MATLAB 里筛即可。

### 用哪一路 ADC 出结果（重要）

**ADS8866（外部 16 位）是最终结果的标准**，内置 ADC 只作对照。
原因：内置是 12 位左移 4 位（有效分辨率 16 码），在 1 pA 量程下量化误差
达 25%；ADS8866 是 1 码，同样条件下 1.5%。

结果行**两路都报**，便于逐点对照（也便于报告里写"内置/外部一致性"）：

```
I=+25.274 nA X=+25.271 nA MODE=1 T=1000ms CAL=+25.270 RAW m=5003 n=6251 INT1=58962 INT2=2601 EXT1=58900 EXT2=2540
```

| 字段 | 含义 |
|---|---|
| `I=` | 由**内置 ADC** 算出的原始值（保持与原固件兼容） |
| `X=` | 由 **ADS8866** 算出的原始值 ← **拟合用的就是这个** |
| `T=` | 实际积分时长（ms）。模式一恒为 1000ms；小电流模式是设定值，撞轨提前收尾时更短 —— 报告里 `I = C·ΔV/T` 的 T 就是它，**必须记录** |
| `CAL=` | `X=` 经分段校准模型后的最终输出（未校准时不出这个字段） |
| ` TIMEOUT` | 后缀。本固件已无模式二，正常不会出现；保留解析是为了兼容 `nano_ammeter` |
| `RAW …` | **模式一专属**的原始量，见下 |

> 上位机的 `I=` 解析正则不锚定行尾，追加字段不会破坏现有解析。

### `RAW` 段：模式一的原始量

| 字段 | 含义 |
|---|---|
| `m=` / `n=` | 窗口内 **POS / NEG 注入的周期数**（式(6) 实际用的是 `m` 与 `n-1`） |
| `INT1=` / `INT2=` | 内置 ADC 那路的**窗口首尾**原始码 |
| `EXT1=` / `EXT2=` | ADS8866 那路的窗口首尾原始码 ← 拟合用这组 |

**为什么要在结果行里带这些**：只报电流值的话，`m`/`n` 和首尾码就丢了，
而下面两件事都必须从**同一次测量**的原始量出发：

1. **`(m+n)` 与 `(m+n-1)` 两种分母之争** —— 只能拿实测的 `m`/`n` 离线各算一遍才有定论
2. **分段系数 `a`/`b` 的拟合** —— 报告的表 4-9~4-14 要的也是这些原始量

小电流模式（`MODE=2`）**不出** `RAW` 段：它不算 `m`/`n`，用的是起点/终点两段
平均，原始量是另一套（`T=` 已经给了它的实际积分拍数）。

`tools/nanoammeter_capture.py` 会把这一段解析进 npz 的 `raw_m` / `raw_n` /
`raw_int1` … 字段；没有这一段时一律记 `-1`（**不伪造成 0**）。

### 校准系数指令

| 指令 | 作用 | 响应 |
|---|---|---|
| `C` | 查询校准状态 | 未校准：`CAL NONE`<br>已校准：`CAL 3 <a0>,<b0> <a1>,<b1> <a2>,<b2>` |
| `K<seg>,<a_ppm>,<b_fA>` | 写入某段系数 | 成功：`CAL SET <seg> <a_ppm>,<b_fA>`<br>失败：`CAL ERR <原因>` |
| `Z` | 清除校准（恢复 a=1, b=0） | `CAL CLEAR` |

响应示例：`CAL 3 998765,-123 1000234,56 999123,-12`

系数存在 Flash 最后一页（`0x0803F800`），掉电不丢。

### 2. 端点直线拟合（提高分辨力）

**实测分辨力现状**（用 09-11 实采数据 + 二阶差分/MAD 估噪声）：

| | 单点噪声 | 单次分辨力 |
|---|---|---|
| 内置 ADC | 48.4 码 | — |
| ADS8866 | 49.0 码 | — |

**两种 ADC 的噪声一样** —— 说明噪声来自模拟前端（积分器 + 电平移位），
不在 ADC 里。**所以换 ADS8866 对分辨力没有帮助**（与早先的猜测相反）。

| 模式 | 单次分辨力 |
|---|---|
| 模式一（1 秒窗口） | **~1.0 pA** |
| 小电流模式（3 秒纯积分，端点 8 点平均） | **~0.13 pA** |

模式一慢在端点用**单点采样**（`voltage_buf[0]` / `voltage_buf[N−1]`）。
端点落在斜坡上（每拍约 480 码），不能直接平均（会挪到质心），
但可以**取末尾 K 点做直线拟合、外推到端点那一拍**：

| K | 噪声 | 分辨力 |
|---|---|---|
| 1（现在） | 68 码 | 1.04 pA |
| 8 | 24 码 | 0.37 pA |
| 16 | 17 码 | 0.26 pA |

### 3. 分母取 (m+n) 还是 (m+n−1)（用户研究中）

- 论文形式 `(m+n)`：实测输出恒为 `0.99984×I + 8.0 pA`
- 固件形式 `(m+n−1)`：第 0 拍的计数对应窗口外的 `[−1, 0]` 段，
  而 `Current_Start()` 保证以 SEL_NEG 开窗 → 多出来的必是 NEG 计数

两者都是**确定性差异，不影响分辨力**；都能被 `I_cal = a·I_raw + b` 吸收。
区别只是论文形式的 `b` 里混了额外的 8 pA（与参考电流共模偏移 11.5 pA 同量级）。

### 4. 已确认的物理事实（供报告用）

**参考电流的共模偏移以 1:1 进入读数**：

```
comp = [(m−n)·I + (m+n)·d] / N      d = (I₊ + I₋)/2
                                └─ 系数 ≈ 1, 无衰减
```

实测 `d = (50.232 − 50.255)/2 = −11.5 pA` → 每个读数偏 +11.5 pA。
**这台仪器的绝对准确度主要由两个参考电流的共模稳定性决定**，
I₊/I₋ 的温漂会 1:1 传进读数（报告 4.7 节不确定度预算里权重最大的一项）。
